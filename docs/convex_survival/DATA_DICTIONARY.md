# BACQE Convex Survival Data Dictionary

## Status

Initial draft.

The definitive schema will be established from the first successful MQL5
research CSV during the ingestion-engine build.

## Source

MQL5 research instrumentation CSV generated by:

`BACQE_Convex_Survival_Engine_v0_1_1b_RESEARCH_INSTRUMENTATION`

## Core identity fields

| Field | Purpose |
|---|---|
| run_id | Identifies the controlled research run |
| bar_time | Timestamp of the evaluated bar |
| symbol | Trading symbol |
| timeframe | Evaluation timeframe |
| bias | Directional classification or trade bias |

## Measured market fields

Expected fields include:

- spread points;
- ATR;
- ATR moving averages;
- ADX;
- EMA separation;
- candle and breakout measurements.

## Attribution fields

Expected fields include:

| Field | Purpose |
|---|---|
| fail_count | Number of failed conditions |
| first_veto | First rejecting condition |
| sole_veto | The only failed condition when exactly one condition fails |
| all_vetoes | Complete collection of failed conditions |
| all_pass | Whether all required conditions passed |

## Schema policy

The ingestion engine will:

- preserve original column names in the raw layer;
- normalise names in the staged layer;
- document all type conversions;
- reject missing mandatory identity fields;
- report malformed values;
- preserve unknown fields rather than silently discard them.
